WHAT THIS IS

A public projection companion

This site is generated from the current learned-model Board B. It carries the approved analyst layer and simulated season ranges, then works entirely in your browser.

The displayed rank is ordinal projected FP/G. The internal safe season-value rank is retained as audit metadata and shown in player details, but it does not drive this public board.

WHAT STAYS LOCAL

Live and private workflows

The public Mock Draft is manual and stored only in your browser. Live ESPN polling, in-season roster ownership, waiver and matchup tools, raw caches, private BBM notes, analyst rationales, and proposal editing remain in the local app.

Those features require a backend or contain review material that should not be embedded in a public static site.

FIELDS

How to read the board

25–26 FP/G
Last season's actual production under the same scoring settings.
Proj Δ
Projected FP/G minus last season's FP/G.
VOR
Projected FP/G above league replacement.
ADP
Market draft position; availability, not projected value.
Season range
Simulated p10, median, and p90 season totals.
Risk
Relative width of that season-total range; lower is more stable.
